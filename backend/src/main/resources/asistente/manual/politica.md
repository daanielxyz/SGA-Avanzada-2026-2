# Política de cancelación

Pantalla «Política de cancelación» del menú, solo para el administrador. Muestra la versión **vigente** y, plegadas, las **versiones anteriores**, que siguen aplicando a las reservas que se hicieron con ellas.

## Cómo funciona
- Cada reserva guarda la versión de la política que estaba vigente cuando se creó, y con esa se calcula siempre lo que se retiene. Publicar una versión nueva **no cambia las reservas ya hechas**.
- La política tiene **tramos por horas de antelación** a la hora de entrada del día de entrada: «con al menos N horas de antelación, retener …». Mientras más cerca de la entrada, normalmente se retiene más.
- Y un valor para el **no-show**: lo que se retiene si el huésped no llega.
- Cada retención puede ser un **porcentaje** (del valor total, de lo pagado o del anticipo exigido) o un **monto fijo** que nunca pasa de esa base. También puede ser «no se retiene nada».

## Publicar una versión nueva
1. «Publicar nueva versión» (o «Publicar la primera versión» si no hay ninguna).
2. En «Si se cancela», arma los tramos: horas de antelación y lo que se retiene. Debe haber un tramo desde 0 horas, las horas no se pueden repetir y hay un mínimo de tramos (lo fija el hotel en Alojamiento › Avanzado).
3. En «Si no se presenta», lo que se retiene por el no-show.
4. Revisa la **vista previa**: así la verá recepción en «Ver política».
5. Publica. Rige para las reservas nuevas desde ese momento.

Si sales con cambios sin publicar, el sistema pregunta. Una versión publicada no se edita: se publica otra.
